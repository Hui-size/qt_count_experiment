# 开发与验证记录

## 阶段 1：工程与界面

- 建立 Qt Widgets / CMake 工程和 Designer 格式 `.ui` 文件。
- 使用垂直布局划分标题、表达式、数字显示、按键区和提示区，按键区为网格布局。
- 初始测试验证显示为 0、显示框只读、20 个按键存在且界面使用布局。
- 原实验中的视频由学生自行录制；开发过程不代录视频。

## 阶段 2：输入处理

- 将数字、小数点、退格、清除、CE 和正负号集中到 CalculatorEngine::dispatch。
- 当前操作数用 QString 保存，保留输入中的尾随小数点；重复小数点忽略，前导零归一。
- 删除至空串或只剩负号时恢复 0；数字输入限制为 15 位。
- 增加 12 条输入序列测试以及真实 QPushButton 鼠标事件测试。

## 阶段 3：四则运算与表达式

- 使用第一个操作数、待执行操作符和等待下一操作数标记管理计算过程。
- 实现四则运算、按输入顺序的连续计算和连续操作符替换。
- 增加四则、小数、连续操作和表达式状态测试，鼠标测试验证 1.5 + 2 = 3.5。
- 根据学生明确要求，使用本机已安装 Qt 6.10.3，工程最低版本设置为 6.10.3。
- 用电脑上安装的 Qt Creator 打开工程；后续扩展边界回归测试并据实际结果修复。

## 阶段 4：边界回归与 qmake 入口

阶段 3 的基础运算通过后，扩展测试实际发现 6 项失败。原始输出保存在本机 F 盘测试目录，以下为实际现象与修复说明。

| 测试输入 | 阶段 3 现象 | 原因 | 修改 | 修复后结果 |
| --- | --- | --- | --- | --- |
| `8 / 0 =` | `inf` | 未判断零除数 | 运算前检查零，进入 Error 状态 | 不能除以零 |
| `2 + 3 =` 后输入 `7` | `57` | 结果没有独立状态 | Result 后数字开启新计算 | 7 |
| `2 + 3 =` 后输入 `.5` | `5.5` | 结果后的小数点继续编辑结果 | Result 后小数点初始化为 `0.` | 0.5 |
| `12 + 3 =` 后退格 | `1` | 退格未限定输入状态 | 仅 FirstOperand / SecondOperand 可退格 | 15 |
| `8 / 0 =` 后输入 `2 + 3 =` | `3` | 错误显示继续参与输入处理 | Error 后数字先完整复位 | 5 |
| `8 / 0 =` 后输入 `.5` | `inf.5` | 无错误恢复入口 | Error 后小数点先完整复位 | 0.5 |

新增明确的五种状态：FirstOperand、OperatorPending、SecondOperand、Result、Error。
同时检查 CE 保留运算、连续操作符、第二操作数退格、连续运算、重复等号及数值溢出恢复。

学生要求可双击 `.pro` 在本机 Qt Creator 中编译运行，因此增加 `qt_count_experiment.pro`，
并将 `main.cpp`、`mainwindow.cpp/.h/.ui` 和引擎文件整理到根目录。
