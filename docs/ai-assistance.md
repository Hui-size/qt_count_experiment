# 一个实际 AI 辅助开发过程

## 问题

完成带键盘事件的 Qt 计算器，并用真实 Git 提交体现分阶段实现、测试和问题修复。
基础计算完成后，需要避免结果拼接输入、除零无穷大显示以及结果被退格误删。

## 用户提示与修正

用户最初要求：“先做实验里面的四，而且做的时候顺便完成 GitHub 的 5 次提交”。
随后确认范围是“四、实验步骤及结果”整节中的程序及相关验证。
用户进一步明确：使用电脑上已安装的 Qt 6.10.3，并提供 `.pro` 文件，方便在 Qt Creator 中编译运行。

## AI 给出的方案

采用 Designer `.ui` 和 Qt Widgets；分离 MainWindow 与 CalculatorEngine。
用明确的五种状态管理第一个操作数、等待操作符、第二个操作数、结果和错误。
鼠标按钮和键盘事件转换为同一 command，调用同一份计算逻辑。

## 实际结果与问题

基础阶段测试通过，但扩展回归测试实际发现 6 项失败，例如：
`8 / 0 =` 显示 `inf`；`2 + 3 =` 后输入 `7` 显示 `57`；`12 + 3 =` 后退格显示 `1`。
详细原始现象、原因和修复对照记录在 `development.md`，未把基础阶段通过误当成最终完成。
后台截图还出现了字体缺失，因此改用本机 Windows 原生平台插件重新检查，确认中文和数字正确显示。

## 实际调整与验证

- 根据用户对 Qt 版本和工程入口的纠正，改用本机 Qt 6.10.3，提供根目录 `.pro` 与窗口源码。
- 在运算前检查除数是否为零，增加独立 Error 状态及恢复入口。
- Result 后的数字、小数点开始新计算；退格仅允许修改输入中的操作数。
- 增加输入、状态、鼠标、键盘、小键盘和混合输入回归测试，最终 59 项功能验证通过。

上述代码修复由 AI 在本次协作中实施，用户提出方向和约束。
